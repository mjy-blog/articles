## 이미지 출력하기 \{#printing-image\}

이미지를 GUI로 보여주기보다는 그냥 BMP파일로 출력하는 식으로 진행할 것이다.

BMP 출력은 궁금하다면 [이 글](/posts/2024-06-14-c-bmp-output)을 참고하자. [`bmp.c`, `bmp.h`](https://gist.github.com/mjy9088/d83644effad787701d5569d4a05d4cbe)를 그대로 사용할 것이다.

```c file=../../static/c/raytracer/write_image.h title="write_image.h"
```

일단 간단한 이미지 출력 함수를 작성해보자

```c file=../../static/c/raytracer/write_image.c title="write_image.c"
```

이미지를 한 픽셀씩 그리는 함수 `renderer_t`를 받고, 이미지 파일로 출력하면서 어디까지 진행됐는지 출력하는 함수이다.

```c file=../../static/c/raytracer/2024-06-16-the-raytracer-project/0/main.c title="tmp/0/main.c"
```

일단 아무 이미지나 나오게 만들어서, 아래 파일들로 테스트하면 아래 이미지가 나온다

```cmake file=../../static/c/raytracer/2024-06-16-the-raytracer-project/0/CMakeLists.txt title="tmp/0/CMakeLists.txt"
```

```shell file=../../static/c/raytracer/2024-06-16-the-raytracer-project/0/build.sh title="tmp/0/build.sh"
```

## 수학적 배경 \{#mathematics-background\}

레이트레이싱은 픽셀마다 광선을 발사해서, 그 광선이 부딛힌 곳의 색을 구하는 방식으로 동작한다.

광선에는 두가지 속성이 있다.

1. 광선이 시작한 위치
2. 광선이 향하는 방향

여기서 위치와 방향이 모두 벡터이다.

벡터는 가변 갈이 배열이라는 의미도 있지만, 여기서의 벡터의 의미는 수학의 그 벡터이다.

3차원 공간상의 위치와 방향을 나타낼 것이기에 3차원 벡터를 사용할 것이다.

```c file=../../static/c/raytracer/f3.h title="f3.h"
```

이런 함수들을 구현할 것이다.

```c file=../../static/c/raytracer/f3.c title="f3.c"
```
